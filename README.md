# lampa-home

Домашний плагин Lampa: включает торренты, прописывает парсер jac.red и два TorrServer (ПК основной, Mi Box запасной) и сам переключается на запасной, если ПК не отвечает.

Подключение в Lampa: Настройки → Расширения → Добавить плагин →
`https://konstantinbuga.github.io/lampa-home/home.js`
